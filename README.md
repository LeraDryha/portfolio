# Portfolio

Personal portfolio of Valeriia Dryha, Product Designer. It replaces the current [Notion portfolio](https://app.notion.com/p/Hi-I-m-Lera-13b44bdcbfce80dfba23e68b5324093f).

**Audience:** hiring managers and recruiters. The site is in English.

**Content**
- Featured case studies: Comfy, Adtelligent, Smart Financial Assistant, GRX Design System
- Prevently: a personal product taken from idea to App Store release ([preventlyapp.com](https://preventlyapp.com))
- More work, writing (Medium) and contacts

**Stack:** Next.js (App Router), TypeScript, MDX content, Vercel.

**Design system:** [`DESIGN.md`](DESIGN.md), "The Proof Sheet": each case shown through one real piece of evidence, one accent colour (Mulberry Ink), Geist with Newsreader italic.

**Status:** Next.js site with the home page and the Comfy case page. Run locally with `npm install` and `npm run dev`. UI kit: `ui/kit.css`, showcase `ui/kit.html`. The full brief is in [`CLAUDE.md`](CLAUDE.md).
