<Chapter id="code" title="From Figma to code">

Tokens are generated from the Figma variables, and the components use nothing else: no raw colours, sizes or font names. PrimeReact gives the behaviour, the keyboard support and the ARIA; it runs without its theme, so every pixel comes from the system.

Every component page in the <Storybook /> has the same parts: its status, a playground, when to use it and what to use instead, examples that run as tests, the design decisions, accessibility (WCAG 2.2 AA in both themes) and a map from the Figma properties to the props, so a developer reads the Figma file and the code the same way.

<Chapter id="learned" title="What I learned">

A component isn’t finished when it looks right in Figma. It’s finished when its states, keyboard behaviour and edge cases are written down where developers read them, and tested there.

Rebuilding real screens is the best test of a system: every gap shows up as a page that has to assemble something itself.
